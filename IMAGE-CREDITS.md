# Architectural reference imagery

## Featured academic projects

The featured project images are rendered excerpts of original presentation boards from Bushra's supplied Wix portfolio. Compact rasterised web editions containing every original PDF page are bundled under `public/documents/`; selected full boards and cover regions are under `public/images/projects/`. Team credits remain visible. These depict academic proposals, not completed buildings.

- The Esplanade: Studio VI, [original portfolio](https://bushratabassumm11.wixsite.com/mysite-2/copy-of-studio-v-1). Source PDF: `c5fd22_d74c337b7a414f509ee95f60492f40b4.pdf`. Individual design with group preliminary site analysis.
- Kepong Meditation Garden: Studio IV, [original portfolio](https://bushratabassumm11.wixsite.com/mysite-2/copy-of-architecture-and-environment). Source PDF: `c5fd22_85510629186c4084bc0632a8ad42ef55.pdf`.
- Echoes of the Wind: Studio IV group project by Lai Nai Shern Paul, Choo Jia Qi and Gazi Bushra Tabassum. Source PDF: `c5fd22_178153e5a99840e8959f6252ebd0ac5d.pdf`, linked on the same Studio IV page. Team attribution is preserved on the project page and presentation board.

The reference photographs below remain only in the earlier study archive.
